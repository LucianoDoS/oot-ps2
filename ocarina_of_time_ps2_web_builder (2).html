Compilación automática en GitHub (`.github/workflows/build-ps2.yml`)

Agrega este archivo a tu repositorio lucianodos/oot-ps2 para que GitHub compile el código C con ps2sdk y publique oot-ps2.elf automáticamente: 

name: Build PS2 ELF
on:
  push:
    branches: [ main, master ]
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    container: ps2dev/ps2dev:latest
    steps:
      - uses: actions/checkout@v4
      - name: Compile oot-ps2.elf
        run: |
          apk add --no-cache python3 make bash
          make -j$(nproc)
      - name: Publish oot-ps2.elf to Release
        uses: softprops/action-gh-release@v2
        with:
          tag_name: latest
          files: |
            oot-ps2.elf
            build/oot-ps2.elf
